# 💳 API NestJS - Payment Service

Este microserviço é responsável por gerenciar as integrações de pagamento do sistema (Gateways, Webhooks e Faturamento).

## 🚀 Como Executar

```bash
# Instalar dependências
npm install

# Rodar em ambiente de desenvolvimento
npm run start:dev
```

## ⚙️ Variáveis de Ambiente Necessárias
* `PORT=3001`
* `PAYMENT_GATEWAY_KEY`
* `WEBHOOK_SECRET`
